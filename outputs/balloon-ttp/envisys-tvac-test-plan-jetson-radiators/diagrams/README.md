# Diagrams

Editable figure sources for [envisys-tvac-test-plan-jetson-radiators.md](../envisys-tvac-test-plan-jetson-radiators.md).

- `atmosphere_0_40km.png` - temperature and pressure vs altitude, 0-40 km, generated by `generate_atmosphere_chart.py`
  from `.tmp/scripts/atmosphere.py` (US76 blended with the Kolkata 12z 19-May sounding below 30 km, same model the
  project's CFD studies use). Re-run `generate_atmosphere_chart.py` with the repo's `.venv` Python if the atmosphere
  model or altitude range changes (two-panel matplotlib figure, altitude on the shared y-axis, no dual-axis overlay).
- `sim_reference_30W_dual_radiator_ascent.png` - copy of `outputs/balloon-ttp/transient-0-40km/figures/transient_temperatures.png`,
  the simulated 30 W dual-radiator transient ascent to 40 km. Used as the Case 1 sanity-check benchmark. If the
  source study is re-run, refresh this copy from the same path.
- `temp_profile_0_30km.jpeg` - client-supplied temperature profile copied from `inputs/Graphs and other inputs/Temp profile 0-30km.jpeg`
- `chamber_pressure_profile.svg` - chamber pressure profile used for all four TVAC tests
- `chamber_temperature_profile.svg` - chamber temperature profile used for all four TVAC tests
- `test_sequence_timeline.svg` - 8-hour execution timeline for the four Envisys tests
