name: step_assembly
description: 'Multi-part STEP assembly ingestion for conjugate heat transfer studies. Imports a multi-body STEP file with the Gmsh OCC kernel, boolean-fragments the parts so contact faces are imprinted and conformal, enumerates every component (name, volume, bounding box) and every part-to-part contact interface, and writes an assignment manifest. Materials and boundary conditions are then assigned per component, and a single conformal mesh is generated with one cellZone per component — ready for splitMeshRegions and chtMultiRegionFoam. Use when the user provides a CAD assembly (heat exchanger, cold plate, enclosure) and wants per-part thermal simulation.'
